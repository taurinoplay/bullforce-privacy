Política de Privacidad – Bull Force

Última actualización: mayo de 2026

Bull Force es una aplicación de registro de entrenamiento físico desarrollada de forma independiente. Esta política explica cómo se maneja la información dentro de la app.

1. Datos que recopilamos

Bull Force no recopila, transmite ni comparte ningún dato personal con servidores externos. Todos los datos que ingresás en la app (rutinas, series, pesos, medidas corporales, logros) se almacenan únicamente en tu dispositivo mediante el almacenamiento local del navegador embebido (localStorage).

2. Permisos utilizados

  • Notificaciones: Se usan para avisarte cuando termina el temporizador de descanso entre series. No se envía ningún dato a servidores externos.
  • Vibración: Para señales de alerta al finalizar el temporizador.
  • Alarma exacta: Para que el temporizador funcione aunque el teléfono esté bloqueado.

3. Datos de terceros

La app utiliza Firebase Realtime Database (Google) únicamente para validar códigos de desbloqueo. Durante este proceso se envía a Firebase el código ingresado por el usuario y la fecha/hora de la validación. No se envía ningún dato personal ni dato de entrenamiento. Firebase puede registrar la dirección IP del dispositivo como parte normal de cualquier conexión a internet. Para más información sobre las prácticas de privacidad de Google, consultá policies.google.com/privacy.

La app no utiliza SDKs de publicidad, analíticas ni redes sociales.

4. Almacenamiento y seguridad

Toda la información se guarda localmente en tu dispositivo. Si desinstalás la app o limpiás los datos desde la configuración del sistema, toda la información se elimina permanentemente. No existe una copia en la nube ni en ningún servidor.

5. Menores de edad

Bull Force no está dirigida a menores de 13 años ni recopila información de ellos de forma intencional.

6. Cambios a esta política

Cualquier cambio a esta política de privacidad se publicará en esta misma página. Te recomendamos revisarla periódicamente.
